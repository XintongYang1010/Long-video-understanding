## Released Repo Capabilities

The current public repo contains:

- `aria_downloader_processor.py`: downloads/processes Aria Everyday Activities sequences when provided an official AEA download-links JSON.
- `video_summarizer.py`: generates action summaries with Gemini/OpenRouter.
- `Generation/main.py`: generates multiple-choice VQA items from processed videos and summaries.
- `Evaluation/run_gaze_renderer.py`: renders gaze/hand visualizations.

The current public repo does not contain a packaged Section 4 VLM-evaluation runner for FR, AD, GC, GM, VMP, and AMEGO, nor the final 5,000+ MCQ benchmark manifest/answer key used to compute the paper table.

## Current Blocker For Paper Table Reproduction

To reproduce Section 4 accuracy numbers rather than just run the released generation pipeline, the following are still required:

- the official benchmark MCQ manifest and answer key, or another released source for the final EgoEverything evaluation set;
- the exact evaluation code/prompts for FR, AD, GC, GM, VMP, and AMEGO settings;
- model/API credentials for the evaluated VLMs.

Without those artifacts, submitting more Slurm jobs would either run only the generation pipeline or fail before producing paper-comparable accuracy results.
